# Workflow

Follow this workflow:

Planner → Implementer → Reviewer

## Planner

Before implementation:

- Analyze the existing codebase.
- Understand the relevant architecture.
- Identify affected files.
- Identify dependencies.
- Identify risks.
- Identify edge cases.
- Define the required tests.
- Produce a technical implementation plan.

Do not implement code during planning.

## Implementer

Execute the Planner's implementation plan.

The Implementer must:

- Implement the solution.
- Add or update tests.
- Run relevant tests.
- Run lint.
- Run typecheck when applicable.
- Review the final diff.

## Reviewer

Review the implementation against:

- Original requirements.
- Planner's implementation plan.
- Existing architecture.
- Tests.
- Regressions.
- Edge cases.
- Security.
- Code quality.

If issues are found, they must be addressed before the task is considered complete.

# Definition of Done

- All requirements are implemented.
- Relevant tests pass.
- Lint passes when applicable.
- Typecheck passes when applicable.
- No unrelated changes remain.
- Reviewer approved the implementation.
